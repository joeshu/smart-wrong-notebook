# AI错题本｜商业化视觉与布局升级方案

## 1. 产品定位

从“错题存储工具”升级为“个人学习闭环工作台”：

> 发现薄弱点 → 快速录入 → AI 解析 → 确认修正 → 间隔复习 → 掌握反馈

视觉关键词：**理性、可信、克制、温暖、效率感**。

不建议继续叠加“炫技 AI”装饰。商业产品的高级感来自：稳定的层级、准确的状态、低认知负担和可预期的操作。

## 2. 首页信息架构

### 首屏只回答三个问题

1. 我今天最应该做什么？
2. 我可以马上开始什么？
3. 我的学习状态有没有变好？

### 推荐结构

1. 顶部问候：日期、用户、设置入口
2. 今日焦点 Hero：今日任务进度、连续学习、主行动
3. 现在就做：今日复习 / 录入错题两个高频入口
4. 学习概览：累计错题、掌握率、连续学习
5. 最近错题：最近 3 条，带状态和下一步
6. 底部导航：首页、错题本、中间录入、复习、设置

## 3. 设计令牌

### 色彩

- 品牌主色：`#5667E8`
- 品牌渐变：`#5667E8 → #8A79EF`
- 主文字：`#172033`
- 次文字：`#7B8498`
- 页面背景：`#F4F6FB`
- 卡片：`#FFFFFF`
- 成功：`#2CAF78`
- 警告：`#EEA942`
- 错误：`#DF6D85`
- 深色主面板：`#1D2641`

### 圆角

- 页面级大卡：24px
- 操作卡：20px
- 普通卡片：18px
- 小标签：8px
- 控件：12–14px

### 间距

统一使用 4 的倍数：

`4 / 8 / 12 / 16 / 20 / 24 / 32`

移动端页面左右边距：16–20px；大屏内容最大宽度：840–1080px。

### 阴影

- 普通卡片：低透明度、低扩散
- 主按钮：品牌色投影
- 不使用大面积重阴影
- 深色模式优先使用边框和表面层级，不依赖阴影

## 4. 首页改造原则

### 4.1 Hero 不要承担太多信息

Hero 只保留：

- 今日一句话目标
- 任务进度
- 一个主按钮

统计、错题列表、AI 状态全部放到下方，避免首屏信息竞争。

### 4.2 主行动必须有唯一优先级

推荐优先级：

1. 有到期复习：主按钮为“开始今日复习”
2. 有待确认题目：主按钮为“继续确认”
3. 无待办：主按钮为“录入第一道错题”

不要同时给三个同权重的 CTA。

### 4.3 录题入口保持全局可见

底部中间使用悬浮录入按钮，但要避免遮挡系统底部手势区域。按钮尺寸 56–64px，圆角 18–22px，带轻量品牌投影。

### 4.4 状态必须可读

错题条目状态统一为：

- 待确认：橙色
- AI 分析中：蓝色
- 待复习：紫色
- 已掌握：绿色
- 分析失败：红色

状态文本比单纯图标更可靠，图标只做辅助。

## 5. 录题/截图页面专项布局

### 推荐流程

`选择图片 → 框选题目 → 预览确认 → 质量检查 → AI 分析`

每一步只提供一个主动作：

- 框选页：完成框选
- 预览页：继续识别
- 质量失败：重新拍摄 / 返回调整
- AI 处理中：查看进度 / 取消

### 录题页视觉原则

- 图片区域占首屏 55–65%
- 控件固定在底部安全区
- 主按钮始终可见
- “重拍”和“放弃”二级操作放在顶部或次级菜单
- 质量问题用“问题 + 解决建议”，不要只显示技术术语

## 6. 错题本页面

### 结构

- 顶部：搜索、筛选、掌握状态摘要
- 筛选条：全部 / 待复习 / 待确认 / 已掌握
- 列表卡：学科色标 + 题干摘要 + 状态 + 最近复习时间
- 大屏：左侧筛选，右侧双栏详情

### 重要原则

不要让用户打开详情后才知道题目状态。列表首屏就要显示“下一步动作”。

## 7. 分析结果页面

推荐信息顺序：

1. 结论摘要
2. 错误定位
3. 正确思路
4. 错因标签
5. 举一反三
6. 下一步练习

AI 内容必须具备：

- 来源清晰
- 置信度可见
- 用户可修改
- 失败可恢复

避免把长篇 AI 文本直接堆在一个卡片里，应拆为可折叠模块。

## 8. 商用级细节清单

- 所有按钮有禁用、加载、失败、重试状态
- 所有图片有加载、缺失、错误占位
- 所有列表有空状态、首次使用引导、错误重试
- 所有页面支持 320px 窄屏和 iPad 宽屏
- 不依赖网络字体，保证离线视觉稳定
- 动效默认 120–240ms，测试环境关闭动效
- 交互目标区域不小于 44×44px
- 颜色不能作为唯一状态信息，必须配文字
- 文案统一使用“下一步动作”表达

## 9. 推荐落地顺序

### P0

1. 统一首页 Hero 和主行动卡
2. 统一状态标签和空状态
3. 重构录题页面底部操作栏
4. 补齐图片加载/缺失/质量失败状态

### P1

1. 错题本列表卡片重做
2. 分析结果模块化
3. iPad 双栏布局
4. 深色模式表面层级优化

### P2

1. 学习周报
2. 个性化主题风格
3. 学科色彩体系
4. 品牌插画和动效资产

## 10. 验收标准

- 新用户 5 秒内知道如何录入第一道错题
- 老用户 3 秒内知道今天该复习什么
- 录题过程任意一步取消都不会误删草稿
- 失败后能明确重试，不需要返回首页猜下一步
- 首页首屏不出现超过 2 个同等优先级主按钮
- 窄屏无横向溢出，宽屏不拉伸成空旷布局
- 暗色模式下文字、边框、状态标签仍有清晰对比度
