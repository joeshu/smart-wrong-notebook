# AI错题本｜商业化视觉落地清单

> 目标：将项目从“功能可用”提升到“可信、精致、可持续运营”的商用产品体验。
>
> 执行方式：每批次独立验收；功能行为不变优先，视觉重构不得牺牲录题、复习、分析主链路。

## 总体验收门槛

- [ ] 新用户 5 秒内找到“录入第一道错题”
- [ ] 老用户 3 秒内知道今日首要任务
- [ ] 任意录题步骤取消不误删草稿
- [ ] 任意失败状态都有原因、建议和重试入口
- [ ] 320px 窄屏无横向溢出
- [ ] iPad/宽屏不出现过度拉伸和空旷
- [ ] 深色模式文字、边框、状态标签可读
- [ ] 交互目标不小于 44×44px
- [ ] 颜色不是唯一状态表达，必须有文字
- [ ] 测试环境无持续动画导致 `pumpAndSettle` 超时

## 批次 2｜截图录题主链路 P0

### 流程

- [x] 选图/拍照 → 框选 → 预览 → 质量检查 → AI 分析
- [x] 取消框选保留草稿
- [x] 放弃录题二次确认并清理文件
- [x] 重拍清理旧草稿和会话
- [x] 阻止质量检查未完成时继续
- [ ] 预览页主按钮固定在底部安全区
- [ ] 框选页图片区域占首屏 55–65%
- [ ] 质量问题展示“问题 + 解决建议”
- [ ] 原图缺失提供重拍入口，不只显示错误
- [ ] 裁剪失败提供重试和返回预览
- [ ] 多次快速点击不重复提交

### 测试

- [ ] 取消框选不删除原图
- [ ] 明确放弃才删除原图
- [ ] 重拍后旧任务不阻塞新任务
- [ ] 图片缺失、质量失败、裁剪失败可恢复
- [ ] 320px/390px/iPad 录题布局
- [ ] 快速重复点击幂等

### 验收标准

- [ ] 用户任意一步返回都知道下一步
- [ ] 不需要返回首页才能恢复录题
- [ ] 失败后不丢原图和已确认内容
