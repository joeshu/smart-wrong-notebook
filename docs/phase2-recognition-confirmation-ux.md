# Phase 2：识别确认 UX

## 目标

AI 解题前建立统一识别确认门禁。单题录入与整页导入复用同一套确认规则：高置信且无结构风险的题可由用户显式授权自动确认，其余题必须留在待处理队列并逐字段确认。

## 已实现

- 单题识别确认工作台：
  - 小屏在原图/文字间切换，大屏并排展示。
  - OCR 原文、用户修正、AI 规范化文本分层展示。
  - 题干、选项、学生答案独立编辑。
  - 低置信字段高亮、逐字段确认。
  - 整题重新识别和题干字段重新识别。
  - 用户确认后的 `normalizedQuestionText` 是后续 AI 分析唯一题干输入。
- 整页导入工作台：
  - 三层文字对照与原图证据预览。
  - 题干、选项、学生答案、公式、表格、图形备注独立维护。
  - 支持整题和字段级重新识别；临时裁剪图在请求完成后删除。
  - “确认高置信度题目”仅处理置信度 ≥ 0.85 且无结构风险的题。
  - 低置信、空题、公式/表格异常、图形缺失和空间风险留在待处理队列。
  - 贴边、重叠、面积或宽高比异常不能通过字段勾选绕过，必须调整题框。
  - 单题重识别失败只保留该题待处理，不阻断整批。
- Pipeline：
  - 移除周期计时器模拟进度。
  - 阶段只由真实调用边界推进：结构提取 → 边界检查 → AI 分析 → 校验保存。
- 失败恢复：
  - 重试当前阶段、切换引擎、手动录入、保留草稿、放弃并清理。
  - 放弃时先检查图片引用，只删除无其他题目引用的临时图。

## 门禁规则

`RecognitionConfirmationPolicy` 是单题和批量共用的纯策略：

1. 自动确认要求高置信、非空、无任何结构或空间风险。
2. 低置信字段必须进入 `confirmedFields`。
3. 公式、选项、表格、图形和学生答案按字段独立确认。
4. 空间风险永远不能靠字段确认绕过。
5. 新单题录入通过系统标签进入确认门禁；确认后标签被移除并转为 `ContentStatus.analyzing`。

## 验证

- `test/domain/services/recognition_confirmation_policy_test.dart` 覆盖自动确认、低置信逐字段确认、结构风险和空间风险硬门禁。
