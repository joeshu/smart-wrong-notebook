# 中国学生错题图片识别能力优化方案

> 本文基于公开网页中的代表性错题本、批改试卷、作文批注和理科公式/示意图样本，以及当前项目代码能力梳理。公开图片仅用于场景分析，不应直接复制进训练集或仓库 fixture。

## 1. 结论

“录错题”不能只做整图 OCR。完整能力应拆成七层：采集质量检测、页面分类、版面解析、专用内容识别、题目组装、作者角色分离、用户确认。最重要的正确性原则是：

1. 原图证据始终保留，任何结构化结果都能回到原图区域核对。
2. 印刷题干、学生作答、教师批改分别存储，不能合并成一段文本。
3. 公式、表格、图形不是普通文本；无法可靠结构化时应保留图片块并要求确认。
4. 整页先分题再识别，单题和整页共用同一套字段确认规则。
5. 低质量、边界不确定、角色不确定、公式或图示不完整时禁止静默进入 AI 分析。

## 2. 网上样本的场景分类

建议不要只按“语数英物化”分类，而采用四个相互独立的标签轴。一个样本可以同时拥有多个标签，回归报告才能准确定位失败原因。

### 2.1 采集来源

| 代码 | 场景 | 主要风险 |
|---|---|---|
| `camera_single` | 相机拍单题 | 透视、阴影、反光、裁掉题干或图 |
| `camera_page` | 相机拍整页/跨页 | 弯曲、书脊、题目跨栏、背景干扰 |
| `scan_pdf` | 扫描试卷/PDF | 多页、旋转页、页眉页脚、答案页混入 |
| `screenshot` | 网课、题库或聊天截图 | UI 水印、状态栏、滚动截断、压缩 |
| `notebook` | 手抄错题本 | 全手写、箭头和补写、题解交错 |

### 2.2 载体与版式

| 代码 | 典型内容 | 识别重点 |
|---|---|---|
| `printed_single` | 干净的印刷单题 | 题干、选项、题号 |
| `marked_exam` | 印刷试题 + 学生笔迹 + 教师红笔 | 三种作者角色分离 |
| `full_worksheet` | 一页多题、多栏和小题 | 阅读顺序、分题边界、跨栏关系 |
| `copied_error_note` | 手抄题目、错因、订正和总结 | 手写段落角色与逻辑关系 |
| `composition` | 作文/阅读理解及批注 | 长文本、行间批注、删除和插入符号 |
| `answer_sheet` | 填涂、方格、答题线、表格 | 作答区定位和空白含义 |

### 2.3 内容块

基础块类型至少扩展为：

`text`、`formula`、`option`、`table`、`chart`、`geometry_diagram`、`circuit_diagram`、`chemistry_structure`、`map`、`answer_area`、`teacher_mark`、`handwriting_note`、`image`。

理科常见风险包括分式上下层错位、根号范围丢失、上下标混淆、单位与变量混淆、几何标注漏读、电路连线误断、化学反应条件或结构式丢失。语文和英语常见风险包括长段落读序错误、行间插入、删除线、圈画、作文批注被并入正文。

### 2.4 字迹与作者角色

| 角色 | 例子 | 产品处理 |
|---|---|---|
| `printed` | 试卷题干、页码 | 进入题干候选 |
| `student` | 作答、草稿、订正 | 单独保存为学生答案/过程 |
| `teacher` | 红勾、打分、批语、标准答案 | 单独保存为教师批改 |
| `unknown` | 颜色不可辨或多人笔迹 | 强制用户选择，不自动合并 |

颜色只能是角色判断的一个信号：学生也可能用红笔，黑白扫描件没有颜色。还需要联合字形、位置、覆盖关系、勾叉模式和上下文判断。

## 3. 优先覆盖的十类回归样本

| 优先级 | 样本类 | 必须正确的输出 |
|---|---|---|
| P0 | 干净印刷单题 | 题干、题号、选项、题型 |
| P0 | 批改后的印刷试卷 | 题干/学生答案/教师批改不串写 |
| P0 | 公式密集数学、物理题 | 公式块边界及 LaTeX/原图证据 |
| P0 | 整页多题、多小题 | 题数、题框、父子题、阅读顺序 |
| P1 | 几何、函数图像、统计图表 | 图块不丢失，文字标注可定位 |
| P1 | 物理电路/受力图 | 线路、节点、箭头和标注保留 |
| P1 | 化学方程式/结构式/装置图 | 上下标、反应条件、结构图保留 |
| P1 | 全手写错题本 | 题目、错因、订正、总结分段 |
| P1 | 语文作文/英语长文批注 | 正文与批注分离，插删关系保留 |
| P2 | 模糊、反光、阴影、折痕、截断 | 明确阻断或重拍提示，不给假确定结果 |

## 4. 建议的数据契约

当前 `QuestionRegion` 已包含 `questionStem`、`formulas`、`tables`、`studentAnswer`、`documentBlocks` 和确认字段，是良好基础；但 `DocumentBlock` 只有类型和内容，无法表达空间证据、作者角色和块级置信度。

建议新增页级 `RecognitionDocument`，并把块模型扩展为：

```text
RecognitionDocument
  id, sourceType, pageType, pageCount, qualityIssues
  pages[]
    size, rotation, readingOrder, blocks[], questionRelations[]

RecognitionBlock
  id, type, polygon, content, contentFormat
  authorRole, inkColor, confidence, riskCodes
  sourceCropRef, parentQuestionId, childBlockIds
```

其中：

- `polygon` 使用归一化坐标，支持非矩形批注和倾斜区域。
- `sourceCropRef` 指向原始页及裁剪坐标，确保可审计。
- `contentFormat` 至少支持 `plain_text`、`markdown`、`latex`、`table_grid`。
- `riskCodes` 由识别生产者直接输出稳定代码，不再依赖中文提示文字反推。
- `questionRelations` 表达大题—小题、题干—选项、答案—订正、批注—目标行等关系。

## 5. 识别流水线

### 5.1 采集质量门

在现有质量检测基础上增加：旋转/透视、眩光、局部阴影、运动模糊、遮挡、纸张边界、内容截断、书页弯曲、分辨率不足。每个问题返回位置、严重度和可执行动作，例如“移开反光”“补拍右下角”“保持镜头平行”。

严重问题阻断上传；轻微问题允许继续但写入风险码。姓名、学校、学号、二维码或人脸出现时提示遮挡/脱敏。

### 5.2 页面分类与版面解析

先判断单题、整页、错题本、作文、答案卡、截图，再走不同布局策略。输出块的多边形、阅读顺序和候选题关系，而不是直接输出一段 Markdown。

整页分题综合使用题号层级、缩进、空白、分隔线、选项排列、答题区域和语义连续性；跨栏或跨页题保留关系，不强行截断。

### 5.3 专用识别路由

- 印刷中文/英文：通用 OCR。
- 中文手写：独立手写模型与字符级置信度。
- 数学公式：块检测后送公式模型，输出 LaTeX，同时保存原图块。
- 表格：输出行列与单元格，不降级成空格拼接文本。
- 图形：检测图类并保留高分辨率裁剪；几何、电路、化学图逐步增加节点/边/标注结构化能力。
- 作文批注：正文行、边栏批语、行间插入、删除线和圈画分别建块与关系。

公开技术资料可作为能力选型参考：PaddleOCR 官方项目提供文档结构化和多语言识别；PaddleOCR-VL 文档明确覆盖印刷、相机扫描和手写公式；UniMERNet 针对真实世界复杂公式提供专门数据集与模型；CASIA-HWDB 可作为中文手写基础能力评估参考。但这些通用基准不能替代中国学生错题场景的自建评测集。

### 5.4 题目组装与角色分离

题目组装发生在块识别之后：先以空间和题号建立候选关系，再以语义校验。禁止把红笔标准答案、打分、学生草稿自动拼入题干。

角色不确定时，确认界面在原图上用不同颜色描边，并提供“题干 / 我的作答 / 老师批改 / 忽略”四个快捷选项。用户更改角色后只重组当前题，无需重新识别整页。

### 5.5 统一确认与 AI 分析门

单题和整页共用以下确认字段：题框、题干、选项、公式、表格/图形、学生答案、教师批改。整页只是批量展示同一套规则。

以下情况不得自动确认：

- 题框或父子题关系不确定；
- 角色为 `unknown`；
- 公式、表格或图形块缺失/不完整；
- 原图被截断或质量问题严重；
- 题干和学生答案空间重叠且无法分离；
- OCR 置信度高但结构一致性校验失败。

AI 错因分析只消费用户确认后的规范化结构，并附带必要的图块，不直接消费未经确认的整页 OCR 文本。

## 6. 数据集和标注方案

### 6.1 首轮规模

建议先建立 240 张脱敏验收集：十个核心类别每类 20 张，再用 40 张覆盖极端质量和组合场景。按小学/初中/高中、学科、采集来源和作者角色分层。这个规模用于工程验收，不代表训练集规模或统计充分性。

每张图标注：

- 页面类型、采集缺陷、隐私区域；
- 所有块的多边形、类型、作者角色和阅读顺序；
- 题目边界及父子关系；
- 印刷/手写真实文本；
- 公式 LaTeX、表格网格；
- 哪些字段必须人工确认；
- 预期的阻断、重拍或降级行为。

### 6.2 来源与合规

- 印刷底稿优先使用教育考试机构公开试题或自行排版的合成题。
- 手写与批改层使用获得同意的脱敏样本，或在公开试题底稿上由志愿者模拟书写。
- 网上搜索到的学生照片只用于发现场景，不直接下载、再发布或提交仓库。
- 删除姓名、学校、班级、学号、准考证号、二维码、人脸及可识别背景。
- 人工真值由两人独立复核；不得由待测模型输出反推。

## 7. 验收指标

报告必须按样本类别、学段、学科、印刷/手写、采集来源分组，不能只给总体平均值。

| 能力 | 指标 | 首轮建议门槛 |
|---|---|---|
| 页面分类 | macro F1 | `>= 0.95` |
| 分题 | 题目边界 recall / precision、IoU | P0 类 recall `>= 0.98`，平均 IoU `>= 0.85` |
| 印刷 OCR | 字符准确率 | `>= 98%` |
| 手写 OCR | 字符准确率 | 单独统计；先建立基线，不与印刷平均 |
| 公式 | 块召回、公式表达匹配、关键符号完整率 | 关键符号缺失为阻断项 |
| 表格 | 单元格检测 F1、结构准确率 | 结构异常不得静默降级 |
| 作者角色 | macro F1、题干污染率 | P0 类角色 F1 `>= 0.95`，教师批改污染题干 `< 1%` |
| 图形 | 图块召回、标注召回 | 图块漏检为阻断项 |
| 产品闭环 | 修改率、重拍率、保存完整率、恢复率 | 保存完整率和恢复率 `100%` |

门槛是拟定的发布门，不是当前项目已达到的结果。手写、公式和图形应先跑真实基线，再锁定分学科阈值。

## 8. 对当前项目的实施顺序

### R1：结构与路由（先做）

1. 新增 `RecognitionDocument`、页类型、块角色、块级风险码和多边形证据。
2. 扩展 `DocumentBlockType`，保持旧 `QuestionRegion` JSON/数据库兼容。
3. 让布局服务直接产出稳定风险码，逐步移除从中文字符串猜风险类型的适配。
4. fixture manifest 增加 `pageType`、`schoolStage`、`contentTags`、`authorRoles` 和块级 expected。

### R2：采集质量与隐私

增加透视、反光、阴影、遮挡和截断检测；在裁剪页展示问题位置及重拍动作；增加隐私提示。此轮直接降低无效识别和误保存。

### R3：专用内容路由

按块调用印刷 OCR、手写 OCR、公式、表格模型；图形先保证检测与原图证据不丢，再逐学科结构化。任何专用模型失败都返回块级错误，不吞掉整题。

### R4：题目组装和确认台

实现父子题关系、跨栏阅读顺序、角色标注和块级重试；单题与整页使用相同确认策略。确认页并排显示原图与结构化字段，支持只修一个块。

### R5：回归与灰度

将 240 张脱敏集接入现有报告工具；按类别发布。线上只记录匿名质量事件、用户修改字段和耗时，不上传原图或题目正文作为遥测。

## 9. 建议优先修改的代码位置

- `lib/src/domain/models/question_region.dart`：扩展块类型、角色、坐标和置信度；或拆出新的 recognition document 模型。
- `lib/src/domain/services/document_layout_service.dart`：返回页类型、块和题目关系。
- `lib/src/data/services/auto_document_layout_service.dart`：实现页面路由和稳定风险码。
- `lib/src/shared/utils/image_quality_detector.dart`：补充几何、光照、遮挡和截断问题。
- `lib/src/domain/services/recognition_confirmation_policy.dart`：增加角色不确定、图块缺失和结构冲突门禁。
- `lib/src/features/ocr/presentation/recognition_confirmation_screen.dart`：增加原图块叠层、角色切换和块级重试。
- `lib/src/features/worksheet_import/presentation/worksheet_region_editor_screen.dart`：展示父子题、跨栏关系与批量确认状态。
- `test/fixtures/accuracy_manifest.json`、`test/fixtures/README.md`：升级分类与块级真值契约。
