# Phase 3B — Core task chain pages

The first product path now uses one visible task model:

1. 拍一道错题
2. 确认识别
3. 查看错误定位
4. 开始练习

## Migrated surfaces

- **Home**: the capture action and four-step path are visible before secondary analytics; content is capped at the shared wide width.
- **Capture**: single-question and worksheet entry choices use semantic colors, token spacing and the shared narrow content width. The confirmation workbench uses the shared expanded breakpoint and keeps image/text evidence in a true two-column layout on large screens.
- **Analysis Loading**: live pipeline and recovery states retain the task context, use the narrow readable width, remove raw colors, and stop continuous rotation under Reduced Motion.
- **Analysis Result**: “错误定位” is promoted ahead of evidence, detailed solution steps are collapsed into one section without nested step cards, and the fixed footer has one filled primary action. A ready result emphasizes “开始练习”; a gated result only offers “保存为待确认” as the primary action.

Routes, repositories, analysis contracts and confirmation gates are unchanged.
